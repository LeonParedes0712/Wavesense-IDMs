# Raw EEG Data

Ubicación prevista para grabaciones EEG originales, timestamps y etiquetas experimentales. Sirve como referencia inalterada de cada sesión.

Agregar datos únicamente de forma local cuando exista un protocolo definido; no modificar manualmente las grabaciones originales. No subir datos EEG reales, información personal ni credenciales al repositorio por defecto. Esta etapa contiene este README y un archivo `.gitkeep`.
