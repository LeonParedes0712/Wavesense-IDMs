# Processed EEG Data

Ubicación prevista para datos derivados de `data/raw/`: señales filtradas, ventanas, matrices de características y etiquetas preparadas para Machine Learning.

Agregar aquí los productos locales de un procesamiento reproducible. No guardar grabaciones originales, secretos ni modelos entrenados. Los datos reales derivados tampoco deben subirse a GitHub por defecto. Esta etapa contiene solo este README.
