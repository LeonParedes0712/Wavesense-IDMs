# Models

> Estado inicial: esta carpeta contiene únicamente documentación. Los archivos, datos y funcionalidades descritos son trabajo futuro.

Esta carpeta está reservada para artefactos de modelos entrenados.

Ejemplos:

- `.pkl`
- `.joblib`
- `.pt`
- `.pth`
- `.onnx`

Los modelos generados NO deben subirse a GitHub por defecto.

La carpeta existe para mantener una ubicación estándar donde los scripts puedan guardar o cargar modelos localmente.

Los resultados de evaluación no deben guardarse aquí; deben ir en `results/`.
