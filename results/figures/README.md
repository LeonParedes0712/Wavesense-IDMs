# Figures

Ubicación prevista para visualizaciones de los experimentos: señales EEG, PSD, matrices de confusión y comparaciones de modelos. Sirve para revisar y comunicar resultados.

Agregar figuras cuando existan experimentos reales. No inventar resultados ni almacenar datasets, modelos o credenciales. Las figuras generadas se mantendrán locales salvo que el equipo seleccione alguna para documentación. Esta etapa contiene este README y un archivo `.gitkeep`.
