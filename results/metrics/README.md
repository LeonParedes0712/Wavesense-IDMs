# Metrics

Ubicación prevista para resultados numéricos de evaluación, como accuracy, precision, recall, F1-score y ROC-AUC, en tablas CSV o JSON.

Agregar métricas obtenidas de experimentos reales, junto con el contexto necesario para interpretarlas. No inventar valores ni guardar aquí datasets, modelos o secretos. Los resultados generados se mantendrán locales salvo selección explícita del equipo para documentación. Esta etapa contiene solo este README.
